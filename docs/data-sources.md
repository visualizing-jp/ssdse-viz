# データ設計

配信データの正本。単位・年次・集計対象・留意点は、統計センターの各セットの解説 PDF（`https://www.nstac.go.jp/files/kaisetsu-*.pdf`）から写している。推測で埋めた値はない。

## 流れ

```
data/raw/SSDSE-*.csv（公式CSV、Shift-JIS、版止め）
  → node scripts/build.ts          scripts/sets/{a..f}.ts
  → public/data/{b,c,d,e,f}.json、public/data/a/meta.json + a/values/{項目コード}.json
  → node scripts/verify.ts         解説PDFの見本値・項目数・内訳の和を検算
```

型は `src/shared/types.ts` をビルドと画面が共有する。

## 共通

- 地域コード `R01000` → 都道府県 `01`、`R01100` → 市区町村 `01100`。全国は `00`。
- 「人口あたり・割合」は画面で計算する。分母と倍率は `scripts/lib/ssds.ts` の `RATE_OVERRIDES` と件数単位の既定（人口10万人あたり）で決め、各項目の `rate` に書き出す。分母は同じセットの項目コード。
  - 人口の内訳（A11・A13・A14・A1700 など）→ 総人口に占める割合
  - 世帯の内訳（A810102 など）→ 一般世帯数に占める割合
  - 進学者数 → 各卒業者数に占める割合（進学率）
  - 空き家数・持ち家数・一戸建住宅数 → 総住宅数に占める割合
  - 非水洗化人口 → 総人口（非水洗化＋水洗化）に占める割合
  - 外国人延べ宿泊者数 → 延べ宿泊者数に占める割合
  - 県内総生産額・県民所得（百万円）、市町村財政（千円）→ 人口1人あたり（千円）
  - それ以外の件数（人・世帯・事業所・施設・校など）→ 人口10万人あたり
  - 率・平均・金額など（%・℃・円・g/人日・m²・ha・－）→ なし

## A 市区町村（SSDSE-A-2026）

- 1741市区町村 × 125項目。行は 0:コード 1:年度 2:項目名 3〜:データ。
- 単位は別表（kaisetsu-A-2026 p.5–7）。社会・人口統計体系の項目コードで B・E と共通なので、`scripts/lib/ssds.ts` の表を3セットで使う。
- 双葉町（R07546）は2020年国勢調査の常住者0。国勢調査由来の値はすべて0で、人口あたりは出さない（分母0は null）。
- 義務教育学校は小学校・中学校と別集計。すべて移行した市区町村は小中学校が0。
- 経済センサスの事業所数・従業者数は個人経営の農林漁家を含まない。
- 境界は `public/geo/ja_municipality_area_5.topojson`（1747図形のうち北方領土6村を除く1741が SSDSE-A と一致）。

## B 県別推移（SSDSE-B-2026）

- 47都道府県 × 12年度（2012〜2023）× 109項目。全国行はない（基準線は47都道府県の中央値）。行は 0:コード 1:項目名 2〜:データ（先頭列が年度）。
- 人口あたりの分母は同じ年度の総人口。
- 気象5項目（B41）は県庁所在市の観測値（東京は千代田区、埼玉は熊谷市、滋賀は彦根市）。2022年宇都宮の降水日数・降水量、2021年富山の降水量は気象庁の「資料不足値」を収録。
- 家計11項目（L32）は県庁所在市（東京は区部）の二人以上の世帯の月間消費支出の年平均値。

## C 家計消費（SSDSE-C-2026）

- 全国・47都道府県庁所在市 × 226項目（世帯人員、食料合計、12中分類、212品目）。行は 0:コード 1:項目名 2〜:データ。
- 単位は世帯人員が人（小数2桁）、他はすべて円。二人以上の世帯の1世帯当たり年間支出金額の 2023〜2025年平均（四捨五入して整数）。
- `LB01`〜`LB12` が中分類、`LBnn` + 4桁が品目で、親は先頭4文字。
- 家計調査の品目分類なので贈答用を含む。分類は 2025年1月改定。
- 特化係数（都市ビュー）＝（都市の品目÷都市の食料合計）÷（全国の品目÷全国の食料合計）。

## D 社会生活（SSDSE-D-2023）

- 男女の別（0_総数・1_男・2_女）× 全国・47都道府県 × 121項目。令和3年社会生活基本調査（調査票A）。行は 0:コード 1:項目名 2〜:データ。
- 単位：MA00 千人（10歳以上）、MB〜MF 行動者率 %（10歳以上、過去1年間＝2020年10月20日〜2021年10月19日）、MG 分、MH 時:分。
- MG01〜MG20 は10歳以上・週全体の総平均。MG51 は平日に通勤・通学をした人の行動者平均、MG52 は15歳以上有業者の週全体、MG53 は10歳以上在学者の平日。
- MH01〜MH04 は10歳以上の平日、MH51・MH52 は15歳以上有業者の平日。配信 JSON では 0時からの分に変換（`clock: true`）。
- スポーツと趣味・娯楽の一部で行動者のいない「－」を SSDSE は 0 としている。
- 1次・2次・3次活動のまとめ方は「令和3年社会生活基本調査 用語の解説」28 行動の種類による（`src/d/data.ts`）。

## E 基本素材（SSDSE-E-2026）

- 全国・47都道府県 × 93項目。行は 0:コード 1:年度 2:項目名 3〜:データ。年次は項目ごと。
- 家計4項目（L3221・L322101・L322102・L322109）は県庁所在市（東京は区部）の二人以上の世帯の月間消費支出の年平均値。
- G5101v2 映画館数は社会・人口統計体系にない項目（経済センサス 産業小分類別結果）。
- 人口あたりの分母は総人口（2024年度）。項目の年次とずれることは画面で注記する。

## F 気候値（SSDSE-F-2023v3）

- 47地点 × 月（1〜12）・年 × 42項目。2020年平年値（1991〜2020年）第4.0.1版。行は 0:コード 1:項目名 2〜:データ（4列目が「01月」〜「12月」「年」）。
- 地点は県庁所在市の気象台等。埼玉は熊谷市、滋賀は彦根市、東京は千代田区の施設を区部として収録。千葉・山口は特別地域気象観測所。
- CN900〜CN920（緯度・経度・標高）は項目ではなく地点の属性として `areas` に入れる。
- 単位は別表（kaisetsu-F-2023v3 p.5）。千葉と山口の雪日数は 2010〜2020年の11年平均。
- 降水量（CN500）と日照時間（CN400）の月の色は気象庁の配色指針の RGB。閾値は月平年値向けに本サイトで割り当てたもの（`src/f/jma.ts`）。
